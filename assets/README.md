# The Gilded Ace assets

See the [project README](../README.md) for the current dashboard, floor lab, setup and limitations.

- `dashboard.css`: green/gold/cream/teal dashboard theme.
- `floor-world.html`, `.css`, `.js`: standalone SVG floor, controls and interactions.
- `floor-motion.js`: geometry, preview routes and decorative guest pathfinding.

Other assets may be retained from earlier versions. The earlier six-section project description is archived in [ASSETS_README_25e345f.md](../docs/archive/ASSETS_README_25e345f.md).
